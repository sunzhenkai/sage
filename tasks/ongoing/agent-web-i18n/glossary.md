## 文体约定

- 按钮用简洁动词（保存 / 删除 / 新建 / 取消）。
- 用「你」，不用「您」。
- 中英混排：英文词两侧留半角空格（如「保存 Package」）。
- 中文标点用全角；数字 / ID / code / URL 保持原样。
- 英文源文案原样提取，不借机修订。

# 新增 Web 中英文切换

**id：** T0004
**status：** archived
**slug：** web-i18n
**创建时间：** 2026-08-15

---

## 概述

为 Agent Web 增加简体中文界面，在中文与英文之间切换，并在首次进入时自动检测语言；无法检测或检测结果不受支持时默认使用中文。

## 背景

当前 `platform/apps/agent-web` 的用户可见文案主要直接写在 React 组件中，界面以英文呈现。现有依赖和源码中未发现统一的 i18n、locale 管理或浏览器语言检测机制，无法为中文用户提供一致的本地化体验。

## 目标

1. 为 Web 页面提供完整、统一的简体中文与英文用户界面文案。
2. 提供用户可操作的中英文切换入口，并让当前界面及时反映所选语言。
3. 首次进入时自动检测可用语言；检测失败、结果缺失或不受支持时使用简体中文。
4. 为语言选择、检测回退和关键页面翻译建立自动化验证。

## 需求说明

- 支持的界面语言至少包括简体中文（`zh-CN`）和英文（`en`）。
- 页面提供清晰可访问的语言切换入口，用户无需刷新即可看到所选语言。
- 首次进入且没有可复用的用户选择时自动检测语言。
- 无法读取语言信息、检测异常或检测到不支持的语言时，统一回退到简体中文。
- 用户可见文案应由统一翻译资源管理，避免同一语义在组件中重复维护两套判断路径。
- 日期、时间等 locale-sensitive 展示应与当前界面语言一致。
- 不改变现有 Chat、Task、Workspace、Provider 和 Profile 的业务行为。

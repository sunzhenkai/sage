看懂 GitHub 热门项目，
而不是只看 star 排名。

一个跑在 Sage 上的声明式 AI app：输入一批 trending 项目快照，输出结构化 digest——每个项目一句话定位、亮点、以及可核查的趋势信号。

missingData[] · 承认盲区

它怎么解读

ENTRY PROMPT · prompts/system.md

一句话定位

优先引用项目 README 自述，压缩成一句可引用的定位；不虚构 repo 与指标。

亮点 → 趋势信号

信号必须落到框架：star 速率 vs 存量、fork/issue 比、贡献者活跃、release 节奏，区分事件驱动与自然增长。

承认盲区

数据缺哪个维度就写进 missingData[]，热度解读不掩盖信息缺口。

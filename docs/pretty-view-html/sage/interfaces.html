6. Coordinator / Engine Adapter

CoordinatorObservation & Reducer

@sage/platform-ports/coordinator-conformance.ts

// reducer 仅输入 observation + command，输出新 observation + result。
// 不调用 adapter、不写 store、不解析 target。
// 重复 commandKey → 复用同一 observation。

enum CoordinatorLifecycleState:
  RUNNING · PAUSED · CANCELLED · COMPLETED · FAILED
  TIMED_OUT · WAITING_FOR_SIGNAL · EFFECT_UNKNOWN

type CoordinatorCommand = Dispatch | Control | Receipt

EngineAdapter

@sage/agent-runtime-conformance

Owner must：实现 observe / reason / plan / act / reflect；不允许直接访问 Model/MCP/Secret、不允许自行签发 CheckpointRef、不允许持有跨 retry 的硬预算、不允许修改 Spec / principal / tenant / target / grant。

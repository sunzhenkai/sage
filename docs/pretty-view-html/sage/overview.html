两个产品层

Agent Library

向其他应用提供可嵌入的 Agent Run、Harness、Skill、Tool、Session 和 Event 能力；提供 Agent 内核、Provider Port、Skill/Tool 端口与可校验 Tool。

不感知 Chat、Task、Temporal Cluster、UI。

Agent Application

提供 Chat UI、Task UI、Temporal Task Runtime 和多环境路由。Chat Service 与 Temporal Activity 都通过同一个 Agent Library 执行 Agent Run。

Agent Application → Agent Library 单向依赖，不允许反向引用。

里程碑

  1. P0–P3

    Agent Library MVP 基础

    contracts / kernel / ports / harness-pi / tool-runtime / state-postgres / chat-domain / task-domain
  2. P4–P5

  3. P6

  4. P7

    production-governance、agent-package-release、agent-release-registry、agent-platform-conformance、agent-runtime-conformance
  5. agent-platform-generalization-validation

    通用 Agent 平台终版基线

    AgentPackageRelease → AgentTaskSpec → Envelope；machine-gate 仍为 BLOCKED/NO-GO

快速开始

  1. 进入工作区根目录：cd platform。
  2. 启动基础设施：docker compose up -d --wait postgres temporal artifact-store。
  3. 启动应用服务：docker compose up -d --build --wait agent-api agent-worker agent-web。
  4. 健康检查：
    • curl http://127.0.0.1:9610/readyz — agent-api
    • curl http://127.0.0.1:9611/readyz — agent-worker
    • curl http://127.0.0.1:14173/ — agent-web

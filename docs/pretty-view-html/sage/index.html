代码接口与技术架构

本包按「事实优先、可独立阅读」整理仓库中的源代码契约与架构文档。所有数据来自 platform/ 工作区与 docs/design/ 的最新交付件；当前实现基线为 v1.1，长期目标态来自 generic-agent-platform-final-architecture 草案。

先记住

  1. Sage 不是简单的 LLM 包装，它是一个双产品层平台：Agent Library 通用执行内核 + Agent Application Chat/Temporal/UI。
  2. 共享公共契约，agent-contracts 暴露 AgentRunSpec/AgentEvent/AgentRunOutcome、AgentTaskSpec/Envelope/Receipt 等 v1 边界。
  3. 唯一权威，单一事实：Chat Store、Task Projection、Agent State、Artifact、Workflow History、Secret 各有 Owner，禁止投影反推 lifecycle。
  4. fail-closed & 防漂移：所有可漂移依赖在 admission 时固化为 AgentTaskSpec；旧 Run 不因活跃版本变化而漂移。

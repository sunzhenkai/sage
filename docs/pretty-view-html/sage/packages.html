依赖核心规则

  • 允许 Agent Application → Agent Library（单向）
  • 允许 Chat Service / Temporal Activity → LocalAgentClient → Agent Library
  • 允许 Task Router → Temporal Client Adapter → selected Temporal Cluster
  • 禁止 Agent Library 直接依赖 Chat / Task / Temporal / Fastify / PostgreSQL
  • 禁止 Agent Application 直接依赖 Pi 专有 API（统一通过 harness-pi）
  • 禁止 Chat / Task UI 直接依赖 Pi / Temporal / PostgreSQL
  • 禁止 Temporal Workflow 直接做 LLM / Tool / 数据库 / 网络 I/O
  • 禁止 Session / Checkpoint 保存明文 Secret

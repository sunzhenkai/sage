终版目标态：通用 Agent 平台

草案文档 docs/design/_cross/generic-agent-platform-final-architecture.md 提出长期目标态：同一 Agent Kernel 同时支持 Chat turn、短运行、长任务、周期任务、人工审批任务和后续未知 workload。

十项核心决策

  1. Agent-first 而非 DAG-first · Agent 自主决定语义步骤
  2. 唯一平台执行语义 · Kernel 统一预算/事件/授权/取消/Receipt/Checkpoint/错误分类
  3. Package 不是运行 authority · 不可变 AgentPackageRelease 经 admission 绑定输入/策略/环境后才有 Spec
  4. AgentTaskSpec 为唯一执行配置 authority · 不引入第二份 Snapshot/Manifest；AgentExecutionEnvelope 只传 Spec 引用、digest、稳定 ID
  5. 双 Host 复用同一 Kernel · Interactive 与 Durable 独立部署、扩缩容，但不复制 Agent 语义
  6. Durable Coordinator 只负责可靠生命周期 · 当前由 Temporal Adapter 实现；Coordinator 内不执行模型/Tool/Memory/DB/Agent 推理
  7. Capability authority 与 MCP 分离 · MCP 是 discovery/schema/transport adapter，不产生授权
  8. 单一事实单一权威 · Lifecycle / 预算 / Tool effect / Checkpoint / Artifact / Chat / 业务事实分别由明确 Store 持有
  9. 状态外置、执行有界 · 每个 bounded run/step 有时间/turn/token/tool/context/artifact/cost 上限；跨边界通过 sealed Checkpoint 恢复
  10. 框架无关以替换可证为准 · 至少两个 Engine Adapter + 一个 Coordinator fake 通过相同 conformance suite

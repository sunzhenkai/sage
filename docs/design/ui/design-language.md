# 设计语言（类 Notion 目标视觉）

- 状态：target visual authority（类 Notion 目标视觉唯一权威）
- 来源：8 张参考产品截图（设置/个人资料、命令面板、用户菜单、收件箱、聊天、任务看板、自动化空态、集成页）
- 关联：结构契约 [`layout-v1.md`](./layout-v1.md)；目标 token 与迁移映射 [`target-token-map.md`](./target-token-map.md)；运行时实现 [`platform/apps/agent-web/src/styles/global.css`](../../../platform/apps/agent-web/src/styles/global.css)
- 取值规则：本文的设计 DNA、语义色、字号、圆角、阴影、图标和动效为目标视觉规范；截图中的近似值只用于解释意图，精确实现值以 `target-token-map.md` 冻结值为准。
- 组件边界：命令面板、看板列、keycap、模板卡、下拉菜单头等是参考截图中的视觉样本，不是当前 `agent-web` 的功能需求；实现只迁移现有 surface，不因样本新建业务功能。

## 1. 一句话定位

Linear / Notion 一派的「安静型效率工具」：中性灰画布、发丝线划分结构、颜色只给状态语义——界面退后，内容优先。

## 2. 设计 DNA

1. **结构靠 1px 发丝线和留白表达**，几乎不用阴影、不用色块切区域；阴影只保留给真正的悬浮层。
2. **90% 界面是灰阶**，彩色只在三处出现：状态、危险操作、选中反馈。
3. **密度分区**：导航区紧凑（行高约 32px），内容区宽松（24–32px 内边距，表单居中约 600px 窄栏）。
4. **空态即引导**：每个空态都是「线性图标 + 一句灰字」；富空态用模板卡片给出口。

## 3. 色彩

| 角色 | 值（读图近似，≈ Tailwind 灰阶） |
|---|---|
| 主内容画布 | `#FFFFFF` |
| 侧栏 / 面板 | gray-50 ≈ `#F9FAFB` |
| 选中 / hover 洗色 | gray-100 ≈ `#F3F4F6` |
| 主文字 | gray-900 ≈ `#111827` |
| 次级文字 | gray-500–600 ≈ `#6B7280` |
| 占位 / 元信息 | gray-400 ≈ `#9CA3AF` |
| 边框（发丝线） | gray-100–200 ≈ `#F3F4F6` / `#E5E7EB` |

语义色（彩色唯一出现的地方）：

- **蓝** = 完成 / 链接 / 焦点环
- **琥珀** = 进行中 / 警告
- **绿** = 审核中 / 成功
- **红** = 已阻塞、退出登录等危险项
- **中性灰** = 待规划 / 待办等待态

着色表面一律用 50 号淡色（amber-50、blue-50、red-50…），不做饱和色块。

## 4. 字体

- 系统无衬线栈（PingFang SC / Inter），中文为主、英文专名混排（GitHub、MCP、HELE-1）。
- 字号阶梯：12px 元信息/计数/keycap → 13px 说明文字 → 14px 正文与导航 → 16px 区块标题；更大标题很少出现。
- 字重克制：400 正文、500 强调（导航、按钮、卡片标题）、600+ 只给页面标题。
- 行高：说明文字宽松（≈1.6），元信息紧凑。
- 等宽字体只用于环境变量/键名的 inline code chip。

## 5. 形状与层级

圆角阶梯（越大越「浮」）：

| 半径 | 用途 |
|---|---|
| 4–6px | keycap、code chip、小徽章 |
| 8–10px | 输入框、按钮、菜单项、集成状态卡 |
| 12px | 任务卡、模板卡 |
| 16px | 命令面板、下拉菜单、看板列、聊天输入框 |

阴影策略：

- 平面结构（面板、卡片、行）：零阴影，只描边。
- 悬浮层（命令面板、下拉）：大而柔的漫射阴影 + 边框。
- 遮罩：整页 blur + 轻遮罩（毛玻璃感）。

## 6. 图标

- Lucide 一类线性描边图标，1.5–2px 描边，随文字继承颜色，永远单色。
- 尺寸：导航 16px、标题旁 16–18px、空态 28–36px。
- 唯一带色的是看板列头状态图标（形状 + 语义色成对出现）。

## 7. 布局骨架

- 三层应用壳：全局左侧栏（~230px，gray-50，分组小标签 + active 灰胶囊）｜上下文列表栏（~330px，白色）｜内容区。面板之间一律发丝线分隔。
- 设置类页面再多一列：二级导航（按「我的账号 / 工作区名」分组）+ 居中内容窄栏（max-width ≈ 600px）。
- 内容两种模式：文档式（表单居中窄栏）/ 全幅式（看板横向铺开）。

## 8. 组件语言（反复出现的模式）

- **导航项**：16px 图标 + 14px 文字；active = 无边框 gray-100 圆角胶囊；hover = 更浅洗色。
- **分组标签**：12px gray-400，上方 16–24px 留白。
- **设置表单卡**：白底、1px 边框、圆角 12px，行间发丝线；每行「左标签+说明 / 右控件」；右下角 `0/2000` 式字符计数。
- **Chip / Tab**：小号描边圆角胶囊；active = 文字加深 + 边框加深或灰底。
- **命令面板**：搜索行（图标 + 输入 + Esc keycap）→ 分组小标签 → 行（图标 + 文字 + 右侧头像/元信息），选中行灰底胶囊。
- **下拉菜单**：头像+名称+邮箱头部 → 发丝线 → 分组标签 → 菜单项（图标 + 文字 + 右侧对勾）→ 红色危险项。
- **看板**：整列 16px 圆角淡色容器（颜色 = 状态），白卡浮在上面。
- **任务卡**：key 行（类型图标 + HELE-1）→ 标题（≤2 行截断）→ 摘要（单行截断）→ 元信息行（16px 头像 + 人名 + 相对时间）。
- **空态**：居中线性图标 + 一句 gray-500 短句（「暂无通知」「无任务」「和你的智能体对话」）；富空态 = 3 列模板卡网格 + 「+ 从空白开始」次级按钮。
- **输入作器**：16px 大圆角输入框 + 右下圆形提交钮（禁用态 gray-300）；上方可挂一条灰底圆角提示条（锁图标 + 说明）。
- **inline code chip**：等宽 12px、gray-100 底、4px 圆角，用于环境变量/键名。
- **keycap**：⌘K / Esc / C，1px 边框、4px 圆角小方块。

## 9. 状态语义系统（看板为样本）

每个状态 = **图标形状 + 语义色 + 列底色** 三位一体：

| 状态 | 图标 | 色 |
|---|---|---|
| 待规划 / 待办 | 空心圆 | 中性灰 |
| 进行中 | 动感图标（图表/时钟） | 琥珀 |
| 审核中 | 圆圈对勾 | 绿 |
| 已完成 | 实心圆对勾 | 蓝 |
| 已阻塞 | 禁止符 | 红 |

卡片自身永远白色中性，只有列容器着色——扫一眼颜色分布即读到进度。

## 10. 文案语气

- 全中文界面 + 英文专有名词（GitHub、MCP、Discord、API Token）。
- 空态短句陈述事实，不煽情：「暂无通知」「还没有自动化」。
- 说明文字带人味：「任何你会在第一天告诉新同事的内容」。
- 按钮动词开头：「新建任务」「创建工作区」「从空白开始」。

## 11. 动效（静帧推断，保守）

- 无渐变、无拟物、无大色块 → 预期 150–200ms 的 opacity / 微位移。
- 悬浮层出现 ≈ scale 0.98→1 + fade；列表项 hover 灰底即时响应。

## 12. 速写提示（给 AI 生成/绘图用）

> 「Linear/Notion 风格的安静效率工具：白底 + gray-50 侧栏，全部结构用 1px gray-200 发丝线，8–16px 圆角阶梯，Lucide 线性单色图标，灰阶之外只有状态语义色（琥珀=进行、蓝=完成、红=阻塞、绿=审核），看板列以 50 号淡色打底、白色圆角卡片浮层，空态是居中线性图标加一句灰字。」

## models.dev

Sage's Provider Catalog interoperates with the public `models.dev` catalog API.

- Source project: [`sst/models.dev`](https://github.com/sst/models.dev)
- API endpoint used at runtime: `https://models.dev/api.json`
- Upstream license: [MIT](https://github.com/sst/models.dev/blob/dev/LICENSE)
- Upstream copyright: Copyright (c) 2025 models. dev

The deterministic test payloads in this package are tiny, hand-authored adaptations of the public `models.dev` object shape. They are deliberately cropped, renamed, and rewritten to exercise validation and projection behavior; they are not copies of the live catalog. The full live payload (approximately 3.7 MiB at design time) is neither vendored nor committed.

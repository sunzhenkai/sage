# Beautiful UI primitives

Adapted from the Beautiful UI shadcn registry (https://www.beautifului.dev/r/registry.json),
MIT License, Copyright (c) 2026 Shane Levine. See `LICENSE` in this folder.

The registry components are scripted demos (timers, ice-cream sample data, extra deps such as
`liveline`, `glimm`, `shadow-plugin`). These files keep their markup, tokens, radii, shadows and
motion, but are rewritten to be data-driven for agent-api data. Source items used:
foundation, loading-state, thinking-state, tool-chips, task-rows, streaming-text, chat-composer,
prompt-bar, approval-card, records-table, insight-cards, code-block, flowchart.
